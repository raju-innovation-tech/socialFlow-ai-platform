# SocialFlow AI – Platform Capability Matrix

| Platform | Official API Used | Auth Method | Required Scopes | Account Eligibility | Supported Capabilities | Restricted Capabilities | Manual-Only / Unavailable | App Review / Tier Requirements | Official Documentation |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **LinkedIn** | LinkedIn Consumer & Community API | OAuth 2.0 | `openid`, `profile`, `email`, `w_member_social`, `w_organization_social` | Personal member account; Verified Company Page | Personal text, images, video, document carousels | Organization posting (`w_organization_social`) | Native Reels (unavailable) | Requires Community Management API approval | [LinkedIn Developer Docs](https://learn.microsoft.com/en-us/linkedin/) |
| **Facebook Pages** | Meta Graph API v20.0 | Facebook Login / OAuth 2.0 | `pages_show_list`, `pages_read_engagement`, `pages_manage_posts` | Facebook Page Admin / Task manager | Feed text, single/multi photos, native video, reels, page insights | Direct User Messaging | Personal Profile Automated Posting (strictly prohibited by Meta) | Meta App Review required for public non-developer users | [Meta Graph API](https://developers.facebook.com/docs/pages-api) |
| **Instagram** | Instagram Graph API | Facebook Login / OAuth 2.0 | `instagram_basic`, `instagram_content_publish`, `instagram_manage_insights` | Instagram Professional (Business or Creator) linked to a Facebook Page | Feed photos, carousels (up to 10), Reels, account insights | Instagram Stories automated publishing | Personal Instagram accounts (strictly unsupported) | Meta App Review required for public non-developer users | [Instagram Graph API](https://developers.facebook.com/docs/instagram-platform/instagram-graph-api) |
| **YouTube** | YouTube Data API v3 | Google OAuth 2.0 | `youtube.readonly`, `youtube.upload`, `userinfo.profile` | Google Account with created YouTube Channel | Long-form video upload, YouTube Shorts, statistics (views, subs) | Daily quota (10,000 units default; upload costs 1,600 units) | Community Tab text posts (no public API endpoint) | Google OAuth App Verification for sensitive scopes | [YouTube Data API](https://developers.google.com/youtube/v3) |
| **X (Twitter)** | Official X API v2 | OAuth 2.0 with PKCE (S256) | `tweet.read`, `tweet.write`, `users.read`, `offline.access` | Standard X Account | Single tweets, multi-tweet threads, polls, images, video (up to 512MB) | Direct Messages (requires elevated permissions) | Free tier limited to 1,500 post writes/month; read requires Basic ($100/mo) | X Developer Portal Project enrollment | [X API v2 Docs](https://developer.x.com/en/docs/twitter-api) |
| **WhatsApp** | Meta WhatsApp Business Platform (Cloud API) | System User Token / WABA ID + Phone Number ID | `whatsapp_business_management`, `whatsapp_business_messaging` | Verified Meta Business Portfolio with registered WABA | Pre-approved template notifications, media attachments, delivery receipts | Marketing template approvals require Meta template review | **Channels, Groups & Communities are NOT supported** for automated SaaS publishing | Meta Business verification + Phone Number registration | [WhatsApp Cloud API](https://developers.facebook.com/docs/whatsapp/cloud-api) |
| **Telegram** | Official Telegram Bot API | Bot Token (`bot<token>`) | `bot_api` (Administrator in channel/group) | Registered Telegram Bot via `@BotFather` | Formatted Markdown/HTML text, photos, videos, albums, interactive polls | Bot must be added as Administrator with `can_post_messages` | Unsolicited direct messaging to arbitrary users without prior /start | None (Instant self-serve via `@BotFather`) | [Telegram Bot API](https://core.telegram.org/bots/api) |
